# Business Promoter Contact Form

A modern contact form with Firebase integration for business promotion services.

## File Structure
- `index.html` - Main contact form page
- `style.css` - Styling for the form
- `ContactUpdate.js` - Firebase integration and form handling
- `config.js` - Firebase configuration (not tracked in git)
- `.env` - Environment variables (not tracked in git)

## Security
- Firebase API keys are stored in environment variables
- Sensitive files are excluded from git using .gitignore
- Firebase security rules are configured to restrict access

## Setup
1. Clone the repository
2. Create a `.env` file with your Firebase configuration
3. Set up Firebase security rules in your Firebase console

## Deployment
The site is deployed using GitHub Pages. The main page is served from `index.html`.

## Features
- Modern, responsive design
- Firebase Realtime Database integration
- Marketing consent management
- Form validation
- Success/error handling
- Secure API key management
